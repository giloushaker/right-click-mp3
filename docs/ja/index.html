右クリック一発で、動画を MP3 に。

MP3 しか再生できない古いプレーヤーのために。エクスプローラーでファイルを選び、右クリックして形式を選ぶ。プログラムはこれだけです。

インストール

  1. 最新リリースから Right-Click-MP3-Setup.exe をダウンロードします。
  2. 実行します。管理者パスワードは不要です。ご自身のユーザーフォルダーにインストールされます。
  3. インストーラーはまだコード署名されていないため、Windows が青い 「Windows によって PC が保護されました」 の画面を出すことがあります。詳細情報 → 実行 を選んでください。
  4. 完了です。再起動もサインアウトも不要で、メニューはすぐに使えます。

スクリプトのほうがよい場合は、ソースの zip をダウンロードして次を実行します:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

使い方

  1. エクスプローラーで 1 個でも 50 個でもファイルを選びます。
  2. 右クリック → 変換 → 形式を選びます。Windows 11 では その他のオプションを確認 の中にあります。
  3. キャンセルボタン付きの小さな進行状況ウィンドウが開きます。新しいファイルは元のファイルと同じフォルダーに作られます。元のファイルが置き換えられたり削除されたりすることはありません。

最初の変換時に、実際の処理を行う無料エンジン ffmpeg（約 30 MB）のダウンロード許可を求めます。以後はすぐに起動します。

アンインストール

設定 → アプリ → インストールされているアプリ → Right Click MP3 → アンインストール。

またはアンインストール用スクリプトを実行します:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

どちらの方法でも、メニュー、ショートカット、プログラムフォルダー、その中の ffmpeg が削除されます。変換済みのファイルはそのまま残ります。

変換サイトではなく、これを使う理由

  • ファイルは自分のパソコンから出ません。アップロードも順番待ちもサイズ制限もありません。
  • 余計なソフトは入りません。インストーラーにはこのプログラムだけが入っています。すべてのコードは GitHub で公開されています。
  • 管理者パスワード不要、アカウント登録も不要です。
  • アルバム丸ごと一度に変換。ページを読み込み直して 1 曲ずつ、ということがありません。

対応形式

変換先: MP3 (192 または 320 kbps)、AAC/M4A、WAV、FLAC。
読み込み: MP4、MKV、MOV、AVI、WEBM、WMV、M4A、AAC、OGG、OPUS、WMA、WAV、FLAC、MP3。

よくある質問

本当に無料ですか？

はい。MIT ライセンスで、有料版も追加販売も催促画面もありません。

なぜ Windows が警告を出すのですか？

コード署名証明書は有料のため、SmartScreen がまだ発行元を認識していません。信頼する前に、ソースコードをすべて読むことも、インストーラーを自分でビルドすることもできます。

ffmpeg とは何ですか？

多くのメディアソフトの土台になっている無料の変換エンジンです。公式の Windows ビルド配布サーバーから、ご自身のユーザーフォルダーにダウンロードされます。

Mac でも使えますか？

いいえ。これは Windows エクスプローラーの機能です。Windows 10 と 11 に対応します。

元のファイルは削除・変更されますか？

ありません。変換後のファイルは元のファイルの隣に作られ、同じ名前が既にある場合は song (1).mp3 になります。
