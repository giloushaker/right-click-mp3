Получите MP3 из любого музыкального файла одним правым кликом.

Для старого плеера, который читает только MP3. Выделите песни в Проводнике Windows, нажмите правую кнопку, выберите формат. С видео всё так же. В этом вся программа.

Установка

  1. Скачайте Right-Click-MP3-Setup.exe из последнего выпуска.
  2. Запустите файл. Пароль администратора не нужен: установка идёт в вашу пользовательскую папку.
  3. Windows может показать синее окно «Система Windows защитила ваш компьютер», потому что установщик пока не подписан. Нажмите Подробнее → Выполнить в любом случае.
  4. Готово. Меню работает сразу — без перезагрузки и выхода из системы.

Предпочитаете скрипты? Скачайте архив с исходным кодом и выполните:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

Как пользоваться

  1. Выделите один файл или пятьдесят в Проводнике.
  2. Правый клик → Преобразовать в → выберите формат. В Windows 11 пункт находится в разделе Показать дополнительные параметры.
  3. Появится небольшое окно хода выполнения с кнопкой отмены. Новые файлы появятся в той же папке, рядом с оригиналами. Ничего не заменяется и не удаляется.

При первом преобразовании программа спросит разрешение скачать ffmpeg (около 30 МБ) — бесплатный движок, который делает саму работу. Дальше запуск мгновенный.

Удаление

Параметры → Приложения → Установленные приложения → Right Click MP3 → Удалить.

Или запустите скрипт удаления:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

Любой из способов удаляет меню, ярлык, папку программы и её копию ffmpeg. Преобразованные файлы остаются на месте.

Почему это, а не сайт-конвертер

  • Файлы не покидают ваш компьютер. Без загрузки на сервер, без очереди, без ограничения размера.
  • Без лишнего софта. В установщике только эта программа и ничего больше. Каждая строка открыта на GitHub.
  • Без пароля администратора и без регистрации.
  • Целые альбомы за раз вместо одного файла на перезагрузку страницы.

Форматы

Преобразует в: MP3 (192 или 320 кбит/с), AAC/M4A, WAV, FLAC.
Читает: MP4, MKV, MOV, AVI, WEBM, WMV, M4A, AAC, OGG, OPUS, WMA, WAV, FLAC, MP3.

Вопросы

Это действительно бесплатно?

Да. Лицензия MIT, без платной версии, без допродаж, без назойливых окон.

Почему Windows предупреждает?

Сертификаты для подписи кода стоят денег, поэтому SmartScreen пока не знает издателя. Вы можете прочитать каждую строку исходного кода или собрать установщик самостоятельно, прежде чем доверять программе.

Что такое ffmpeg?

Бесплатный движок преобразования, на котором построено большинство медиапрограмм. Он скачивается с официального сервера сборок для Windows в вашу пользовательскую папку.

Работает ли это на Mac?

Нет — это возможность Проводника Windows. Windows 10 и 11.

Изменяются или удаляются оригиналы?

Никогда. Преобразованный файл создаётся рядом с оригиналом, а если такое имя занято, он станет песня (1).mp3.
