Ottieni un MP3 da qualsiasi file musicale, con un clic destro.

Per il vecchio lettore MP3 che legge solo MP3. Seleziona i tuoi brani in Esplora risorse, fai clic destro, scegli un formato. Con i video funziona allo stesso modo. Il programma è tutto qui.

Installazione

  1. Scarica Right-Click-MP3-Setup.exe dall'ultima versione pubblicata.
  2. Avvialo. Nessuna password di amministratore: si installa nella tua cartella utente.
  3. Windows potrebbe mostrare il riquadro blu «Windows ha protetto il PC», perché il programma di installazione non è ancora firmato. Fai clic su Ulteriori informazioni → Esegui comunque.
  4. Fatto. Il menu funziona subito, senza riavvio né disconnessione.

Preferisci gli script? Scarica lo zip dei sorgenti ed esegui:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

Come si usa

  1. Seleziona un file, o cinquanta, in Esplora file.
  2. Clic destro → Converti in → scegli il formato. Su Windows 11 si trova in Mostra altre opzioni.
  3. Compare una piccola finestra di avanzamento con il pulsante Annulla. I nuovi file appaiono nella stessa cartella, accanto agli originali. Nulla viene sostituito o cancellato.

Alla prima conversione l'app chiede il permesso di scaricare ffmpeg (circa 30 MB), il motore gratuito che fa il lavoro vero. Dopo di che parte all'istante.

Disinstallazione

Impostazioni → App → App installate → Right Click MP3 → Disinstalla.

Oppure esegui lo script di disinstallazione:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

In entrambi i casi vengono rimossi il menu, il collegamento, la cartella del programma e la sua copia di ffmpeg. I file convertiti restano dove sono.

Perché questo invece di un sito di conversione

  • I tuoi file restano sul tuo computer. Nessun caricamento, nessuna coda, nessun limite di dimensione.
  • Niente programmi indesiderati. Il programma di installazione contiene solo questa applicazione. Ogni riga è pubblica su GitHub.
  • Nessuna password di amministratore e nessun account da creare.
  • Interi album in una volta, invece di un file per ogni ricaricamento di pagina.

Domande

È davvero gratuito?

Sì. Licenza MIT, nessuna versione a pagamento, nessun extra da vendere, nessuna finestra insistente.

Perché Windows mi avvisa?

I certificati per firmare il codice costano, quindi SmartScreen non riconosce ancora l'autore. Puoi leggere ogni riga del sorgente, o compilare tu stesso il programma di installazione, prima di fidarti.

Che cos'è ffmpeg?

Il motore di conversione gratuito su cui si basa gran parte dei software multimediali. Viene scaricato dal server ufficiale delle build per Windows nella tua cartella utente.

Funziona su Mac?

No: è una funzione di Esplora risorse di Windows. Windows 10 e 11.

Cancella o modifica gli originali?

Mai. Il file convertito viene scritto accanto all'originale e, se quel nome è già occupato, diventa canzone (1).mp3.
