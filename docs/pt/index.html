Transforme um vídeo em MP3 com um clique direito.

Para aquele leitor de MP3 antigo que só toca MP3. Selecione os ficheiros no Explorador do Windows, clique com o botão direito e escolha um formato. O programa é só isto.

Instalação

  1. Transfira o Right-Click-MP3-Setup.exe da versão mais recente.
  2. Execute-o. Sem palavra-passe de administrador: instala na sua própria pasta de utilizador.
  3. O Windows pode mostrar a caixa azul «O Windows protegeu o seu PC», porque o instalador ainda não está assinado. Clique em Mais informações → Executar mesmo assim.
  4. Pronto. O menu funciona logo, sem reiniciar nem terminar sessão.

Prefere scripts? Transfira o zip do código-fonte e execute:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

Como usar

  1. Selecione um ficheiro, ou cinquenta, no Explorador de Ficheiros.
  2. Botão direito → Converter para → escolha um formato. No Windows 11 está dentro de Mostrar mais opções.
  3. Aparece uma pequena janela de progresso, com botão Cancelar. Os novos ficheiros ficam na mesma pasta, ao lado dos originais. Nada é substituído nem apagado.

Na primeira conversão a aplicação pede autorização para transferir o ffmpeg (cerca de 30 MB), o motor gratuito que faz o trabalho real. Depois disso arranca de imediato.

Desinstalação

Definições → Aplicações → Aplicações instaladas → Right Click MP3 → Desinstalar.

Ou execute o script de desinstalação:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

Qualquer uma das formas remove o menu, o atalho, a pasta do programa e a sua cópia do ffmpeg. Os ficheiros convertidos ficam onde estão.

Porquê isto em vez de um site de conversão

  • Os seus ficheiros não saem do computador. Sem envios, sem filas, sem limite de tamanho.
  • Sem programas indesejados. O instalador contém este programa e mais nada. Cada linha é pública no GitHub.
  • Sem palavra-passe de administrador e sem conta para criar.
  • Álbuns inteiros de uma vez, em vez de um ficheiro por cada recarregamento de página.

Formatos

Converte para: MP3 (192 ou 320 kbps), AAC/M4A, WAV, FLAC.
Lê: MP4, MKV, MOV, AVI, WEBM, WMV, M4A, AAC, OGG, OPUS, WMA, WAV, FLAC, MP3.

Perguntas

É mesmo gratuito?

Sim. Licença MIT, sem versão paga, sem extras para vender, sem janelas insistentes.

Porque é que o Windows avisa?

Os certificados de assinatura de código custam dinheiro, por isso o SmartScreen ainda não reconhece o autor. Pode ler cada linha do código, ou compilar o instalador você mesmo, antes de confiar.

O que é o ffmpeg?

O motor de conversão gratuito em que assenta a maior parte do software multimédia. É transferido do servidor oficial de compilações para Windows para a sua pasta de utilizador.

Funciona num Mac?

Não — isto é uma funcionalidade do Explorador do Windows. Windows 10 e 11.

Apaga ou altera os originais?

Nunca. O ficheiro convertido é escrito ao lado do original e, se esse nome já existir, passa a musica (1).mp3.
