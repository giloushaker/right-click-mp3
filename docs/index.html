Install

  1. Download Right-Click-MP3-Setup.exe from the latest release.
  2. Run it. No administrator password: it installs into your own user folder.
  3. Windows may show a blue "Windows protected your PC" box, because the installer is not code-signed yet. Click More info → Run anyway.
  4. Done. The menu works right away — no reboot, no sign-out.

Prefer scripts? Download the source zip and run:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

Use it

  1. Select one file or fifty in File Explorer.
  2. Right-click → Convert To → choose a format. On Windows 11 it lives under Show more options.
  3. A small progress window runs, with a Cancel button. The new files appear in the same folder, next to the originals. Nothing is replaced or deleted.

The first conversion asks permission to download ffmpeg (about 30 MB), the free engine that does the actual work. After that it starts instantly.

Uninstall

Settings → Apps → Installed apps → Right Click MP3 → Uninstall.

Or run the uninstall script:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

Either one removes the menu, the shortcut, the program folder and its copy of ffmpeg. Your converted files stay where they are.

Why this instead of a converter website

  • Your files stay on your computer. No upload, no queue, no size limit.
  • No adware. The installer contains this program and nothing else. Every line is public on GitHub.
  • No admin password and no account to create.
  • Whole albums at once instead of one file per page reload.

Formats

Reads: MP4, MKV, MOV, AVI, WEBM, WMV, M4A, AAC, OGG, OPUS, WMA, WAV, FLAC, MP3.

Questions

Is it really free?

Yes. MIT licensed, no paid tier, no upsell, no nag screen.

Why does Windows warn about it?

Code-signing certificates cost money, so SmartScreen does not recognise the publisher yet. You can read every line of the source, or build the installer yourself, before trusting it.

What is ffmpeg?

The free conversion engine most media software is built on. It is downloaded from the official Windows build server into your user folder.

Does it work on a Mac?

No — this is a Windows Explorer feature. Windows 10 and 11.

Does it delete or change my originals?

Never. The converted file is written next to the original, and if that name is taken it becomes song (1).mp3.
