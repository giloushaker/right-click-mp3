右键一下，把任意音乐文件变成 MP3。

为只能播放 MP3 的老式播放器而做。在文件资源管理器中选中歌曲，点右键，选一个格式。视频也是同样的做法。整个程序就这么简单。

安装

  1. 从最新发布版本下载 Right-Click-MP3-Setup.exe。
  2. 运行它。不需要管理员密码：程序安装在你自己的用户文件夹中。
  3. 由于安装程序尚未进行代码签名，Windows 可能会显示蓝色的“Windows 已保护你的电脑”提示。点击更多信息 → 仍要运行。
  4. 完成。菜单立即可用，无需重启或注销。

更喜欢用脚本？下载源码压缩包后运行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

使用方法

  1. 在文件资源管理器中选中一个文件，或者五十个。
  2. 右键 → 转换为 → 选择格式。在 Windows 11 中，它位于显示更多选项里。
  3. 会出现一个带取消按钮的小进度窗口。新文件保存在同一个文件夹里，就在原文件旁边。原文件不会被替换或删除。

第一次转换时，程序会请求下载 ffmpeg（约 30 MB），也就是真正负责转换的免费引擎。之后启动就是瞬间的事。

卸载

设置 → 应用 → 已安装的应用 → Right Click MP3 → 卸载。

或者运行卸载脚本：

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

两种方式都会删除菜单、快捷方式、程序文件夹以及其中的 ffmpeg。已转换好的文件会保留在原处。

为什么用它，而不是在线转换网站

  • 文件不会离开你的电脑。无需上传，不用排队，也没有大小限制。
  • 不捆绑其他软件。安装包里只有这一个程序。每一行代码都公开在 GitHub 上。
  • 不需要管理员密码，也不用注册账号。
  • 整张专辑一次搞定，不用每转一个文件就刷新一次网页。

常见问题

真的免费吗？

是的。采用 MIT 许可证，没有付费版本，没有附加销售，也没有反复提醒的弹窗。

为什么 Windows 会发出警告？

代码签名证书需要花钱，所以 SmartScreen 还不认识这个发布者。在信任它之前，你可以逐行阅读源代码，或者自己编译安装程序。

ffmpeg 是什么？

大多数媒体软件都基于它的免费转换引擎。程序会从官方的 Windows 构建服务器把它下载到你的用户文件夹。

能在 Mac 上用吗？

不能，这是 Windows 文件资源管理器的功能。支持 Windows 10 和 11。

会删除或修改原文件吗？

绝不会。转换后的文件写在原文件旁边；如果同名文件已存在，就会变成 song (1).mp3。
