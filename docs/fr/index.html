Obtenez un MP3 depuis n'importe quel fichier de musique, d'un simple clic droit.

Pour le vieux baladeur qui ne lit que le MP3. Sélectionnez vos morceaux dans l'Explorateur Windows, faites un clic droit, choisissez un format. Les vidéos fonctionnent pareil. C'est tout le programme.

Installation

  1. Téléchargez Right-Click-MP3-Setup.exe depuis la dernière version publiée.
  2. Lancez-le. Aucun mot de passe administrateur : l'installation se fait dans votre dossier utilisateur.
  3. Windows peut afficher un écran bleu « Windows a protégé votre ordinateur », car l'installateur n'est pas encore signé. Cliquez sur Informations complémentaires → Exécuter quand même.
  4. Terminé. Le menu fonctionne immédiatement, sans redémarrage ni déconnexion.

Vous préférez les scripts ? Téléchargez l'archive des sources et lancez :

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

Utilisation

  1. Sélectionnez un fichier, ou cinquante, dans l'Explorateur de fichiers.
  2. Clic droit → Convertir en → choisissez un format. Sous Windows 11, c'est dans Afficher plus d'options.
  3. Une petite fenêtre de progression s'affiche, avec un bouton Annuler. Les nouveaux fichiers apparaissent dans le même dossier, à côté des originaux. Rien n'est remplacé ni supprimé.

À la première conversion, l'application demande l'autorisation de télécharger ffmpeg (environ 30 Mo), le moteur gratuit qui fait le vrai travail. Ensuite, le démarrage est instantané.

Désinstallation

Paramètres → Applications → Applications installées → Right Click MP3 → Désinstaller.

Ou lancez le script de désinstallation :

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

Dans les deux cas, le menu, le raccourci, le dossier du programme et sa copie de ffmpeg sont supprimés. Vos fichiers convertis restent en place.

Pourquoi ceci plutôt qu'un site de conversion

  • Vos fichiers restent sur votre ordinateur. Aucun envoi, aucune file d'attente, aucune limite de taille.
  • Aucun logiciel indésirable. L'installateur ne contient que ce programme. Tout le code est public sur GitHub.
  • Aucun mot de passe administrateur et aucun compte à créer.
  • Des albums entiers d'un coup, au lieu d'un fichier par rechargement de page.

Questions

C'est vraiment gratuit ?

Oui. Licence MIT, aucune version payante, aucune offre supplémentaire, aucun rappel insistant.

Pourquoi Windows affiche-t-il un avertissement ?

Les certificats de signature de code coûtent cher, donc SmartScreen ne reconnaît pas encore l'éditeur. Vous pouvez lire chaque ligne du code source, ou compiler l'installateur vous-même, avant de faire confiance au programme.

Qu'est-ce que ffmpeg ?

Le moteur de conversion gratuit sur lequel repose la plupart des logiciels multimédias. Il est téléchargé depuis le serveur officiel des versions Windows, dans votre dossier utilisateur.

Est-ce que ça marche sur Mac ?

Non : c'est une fonction de l'Explorateur Windows. Windows 10 et 11.

Mes fichiers d'origine sont-ils modifiés ou supprimés ?

Jamais. Le fichier converti est écrit à côté de l'original, et si ce nom est déjà pris il devient chanson (1).mp3.
