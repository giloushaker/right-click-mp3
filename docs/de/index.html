Installation

  1. Laden Sie Right-Click-MP3-Setup.exe aus der neuesten Version herunter.
  2. Starten Sie die Datei. Kein Administratorkennwort nötig: Die Installation erfolgt in Ihrem eigenen Benutzerordner.
  3. Windows zeigt eventuell das blaue Fenster „Der Computer wurde durch Windows geschützt“, weil das Installationsprogramm noch nicht signiert ist. Klicken Sie auf Weitere Informationen → Trotzdem ausführen.
  4. Fertig. Das Menü ist sofort da — ohne Neustart, ohne Abmelden.

Lieber per Skript? Quellcode-ZIP herunterladen und ausführen:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install-user.ps1

Verwendung

  1. Markieren Sie eine Datei oder fünfzig im Datei-Explorer.
  2. Rechtsklick → Konvertieren in → Format wählen. Unter Windows 11 steht es unter Weitere Optionen anzeigen.
  3. Ein kleines Fortschrittsfenster mit Abbrechen-Schaltfläche erscheint. Die neuen Dateien liegen anschließend im selben Ordner neben den Originalen. Nichts wird ersetzt oder gelöscht.

Vor der ersten Konvertierung fragt das Programm, ob es ffmpeg herunterladen darf (rund 30 MB) — die kostenlose Engine, die die eigentliche Arbeit macht. Danach startet alles sofort.

Deinstallation

Einstellungen → Apps → Installierte Apps → Right Click MP3 → Deinstallieren.

Oder das Deinstallationsskript ausführen:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\RightClickMP3\uninstall-user.ps1"

Beide Wege entfernen das Menü, die Verknüpfung, den Programmordner und die dortige ffmpeg-Kopie. Ihre konvertierten Dateien bleiben unberührt.

Warum das statt einer Konverter-Website

  • Ihre Dateien bleiben auf Ihrem Rechner. Kein Upload, keine Warteschlange, keine Größenbeschränkung.
  • Keine Beigaben. Das Installationsprogramm enthält nur dieses Programm. Jede Zeile ist öffentlich auf GitHub.
  • Kein Administratorkennwort und kein Konto, das man anlegen muss.
  • Ganze Alben auf einmal statt einer Datei pro Seitenaufruf.

Fragen

Ist es wirklich kostenlos?

Ja. MIT-Lizenz, keine Bezahlversion, keine Zusatzangebote, keine Erinnerungsfenster.

Warum warnt Windows davor?

Zertifikate zum Signieren kosten Geld, deshalb kennt SmartScreen den Herausgeber noch nicht. Sie können jede Zeile des Quellcodes lesen oder das Installationsprogramm selbst bauen, bevor Sie ihm vertrauen.

Was ist ffmpeg?

Die kostenlose Konvertierungs-Engine, auf der die meiste Mediensoftware aufbaut. Sie wird vom offiziellen Windows-Build-Server in Ihren Benutzerordner geladen.

Läuft das auf einem Mac?

Nein — das ist eine Funktion des Windows-Explorers. Windows 10 und 11.

Werden meine Originale gelöscht oder verändert?

Nie. Die konvertierte Datei wird neben das Original gelegt; ist der Name belegt, heißt sie lied (1).mp3.
